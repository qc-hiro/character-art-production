# 角色美术制作 Skill

用于角色设计、三视图、姿势变体、Q版与审图返修的通用方法库。

## 访问

本库公开，任何人都可以查看与下载。直接写入由仓库所有者维护；不向使用者授予协作者权限。使用者可以提交反馈或 Pull Request 建议，是否合并由所有者决定。

公开访问不授予任何私人项目资料的访问权。本库只包含通用方法，不包含项目素材与私有资料。

## 安装与更新

在 Codex 中提供本仓库链接，请其把仓库安装为 `character-art-production` skill；需要更新时，请其检查该仓库最新的已发布版本，查看变更，再更新本地 skill。公开下载无需受邀，也不需要共享凭据。

如果手动管理，把仓库克隆到本机 Codex 的 `skills/character-art-production` 目录，然后调用 `$character-art-production`。更新前检查本地修改；有修改时先保留并解决冲突，不覆盖。建议使用发布标签选择稳定版本。

仓库更新不会自动更新每个人已安装的本地副本。需要拉取更新或重新安装；当前仓库没有后台自动同步程序。

## 持续演进

1. 使用者提交脱敏的使用反馈或失败案例：预期、实际问题、适用条件。
2. 维护者从反馈提炼通用美术规则，在分支上作最小必要修改。
3. Pull Request 说明行为变化，并检查脱敏、参考用途与用户意图是否保持正确。
4. 自动检查通过后，维护者审阅合并，更新版本与变更记录并发布稳定标签。
5. 使用者更新本地安装；发现回归可回到上一稳定标签。

这是一套基于实际使用证据的维护流程，不会自动读取私人项目资料，也没有无人值守自动改写 skill。PR 审阅是维护约定，是否由 GitHub 强制执行取决于仓库保护配置与计划支持。

具体贡献要求见 [CONTRIBUTING.md](CONTRIBUTING.md)，当前版本见 [VERSION](VERSION)，变更见 [CHANGELOG.md](CHANGELOG.md)。
